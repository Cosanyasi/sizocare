# SizoCare — Architecture Decision Records

This directory tracks architectural decisions made during implementation.
Each ADR follows the template below.

## Existing ADRs (from ARD)

- **ADR-001**: RLS as Primary Authorization Boundary — see [Architecture Requirements](../SizoCare_Architecture_Requirements.md) Appendix A
- **ADR-002**: Envelope Encryption Timing — see [Architecture Requirements](../SizoCare_Architecture_Requirements.md) Appendix A

## Template

```markdown
# ADR-NNN: Title

## Status
Proposed | Accepted | Deprecated | Superseded

## Context
What is the issue that we're seeing that is motivating this decision?

## Decision
What is the change that we're proposing?

## Consequences
What becomes easier or more difficult to do because of this change?
```
